# Core Java Coding Practice — 40 Problems

A collection of 40 Java coding problems to strengthen programming logic, problem-solving skills, and understanding of Core Java concepts.

## 📚 Topics Covered

### 1. Basic Logic — 20 Problems
- Strings and Arrays
- Number-based problems
- Loops and Conditions
- Pattern Programs

### 2. Collections — 10 Problems
- ArrayList and LinkedList
- HashMap and HashSet
- Comparator
- Frequency and Duplicate Problems

### 3. Java 8 — 10 Problems
- Lambda Expressions
- Stream API
- `map()` and `filter()`
- `sorted()`
- `groupingBy()`
- `max()`, `min()`, and Optional

## 🛠️ Technologies
- Java
- Core Java
- Java Collections Framework
- Java 8 Features

## ▶️ How to Run

1. Install the Java JDK.
2. Clone this repository.
3. Open a Java file in your IDE or terminal.
4. Compile and run the program.

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the appropriate class name.

To improve Java fundamentals, build consistent coding habits, and prepare for Java Developer technical interviews.
